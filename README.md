แอป Windows สำหรับสตรีมเมอร์ VTuber: **ของขวัญจาก TikTok LIVE → ตัวละครใน VTube Studio มีท่าตามของขวัญ**
คนดูส่งกุหลาบ ตัวละครโดนปาหัว · ส่งโดนัท โดนัทบินเข้าปาก · ส่งรถ รถพุ่งมาชน · ส่งวาฬ วาฬว่ายผ่านแล้วพ่นน้ำ

ทำมาสำหรับ **TikTok LIVE Studio** ไม่ต้องใช้ OBS: ทุกอย่างเกิดในหน้าต่าง VTube Studio เลยขึ้นในไลฟ์ได้ทันที
แอปไม่ขอรหัสผ่าน TikTok ใช้แค่ชื่อบัญชี

- เวอร์ชันปัจจุบัน: **v1.0.0** ([มีอะไรบ้าง](CHANGELOG.md))

## ทำอะไรได้บ้าง

**🎁 ของขวัญ → ท่าของตัวละคร**
- รู้จักของขวัญ TikTok 258 ชิ้น พร้อมรูปจริง แต่ละชิ้นมีท่าของตัวเอง 26 แบบ เช่น ปาใส่หัว, หมวกหล่นใส่หัว, บินเข้าปาก, คล้องคอ, รถชน, สัตว์มานั่งบนหัว, เครื่องดนตรี, ดาวตก, แช่แข็ง, ไฟช็อต
- ปรับแยกได้ทุกหมวดและทุกชิ้น: เปิด/ปิด, ขนาด, ความแรง, ความเร็ว, จำนวนสูงสุด 1–300 ชิ้นต่อครั้ง, เสียง, ความดัง
- กฎของขวัญตั้งเองได้: ตามชื่อของขวัญ หรือตามช่วงราคาเหรียญ

**👑 ของขวัญแพง**
- ยิ่งแพงยิ่งอลัง 3 ระดับ: โชว์ตัวใหญ่กลางจอ, พลุ, ฝนเหรียญ, แสงรุ้ง, มงกุฎบนหัว
- ป้ายชื่อ "ขอบคุณ ○○ ที่ส่ง ..." ในหน้าต่าง VTube Studio
- ของแพงได้เล่นเดี่ยว ของอื่นรอคิวแล้วทยอยออก
- ฉากพิเศษ 9 แบบ: วาฬ, สิงโต, มังกร, ฟีนิกซ์, กุหลาบ, อวกาศ, แข่งรถ, ฝนดาวตก, อัญมณี

**🎯 เล็งแม่น ตามตัวละคร**
- ลากเป้าให้ตรงหัว และตั้งเป้าแยกตามหมวดได้ (ของกินเล็งปาก, สร้อยเล็งคอ)
- 📌 ล็อกกับโมเดล: คลิกที่ตัวละครใน VTube Studio ครั้งเดียว ของจะตามจุดนั้นแม้ย้าย ซูม หรือขยับหัว จำแยกตามโมเดล

**💬 แชทและคนดู**
- อ่านแชทออกเสียง หลายเสียง ทุกภาษา เลือกเสียงตามภาษาให้เอง กรองคำต้องห้าม ลิงก์ และคนที่ไม่อยากให้อ่าน
- ขอบคุณอัตโนมัติด้วยเสียง เมื่อมีคนส่งของขวัญ ฟอลโลว์ หรือแชร์
- คำสั่งแชทฟรี เช่น `!โป๊ก` ให้คนดูเล่นกับตัวละครได้โดยไม่ต้องส่งของขวัญ
- คอมโบ: ส่งของเดิมรัว ๆ ท่ายิ่งแรงขึ้น

**🎛️ ระหว่างไลฟ์**
- ⏸ พักเอฟเฟกต์ด้วยปุ่มหรือคีย์ลัด (กดได้แม้อยู่ในเกม) ของที่ส่งมาตอนพักรอไว้ก่อน
- จำกัดจำนวนเอฟเฟกต์ต่อนาที กันจอรก
- มิกเซอร์เสียง: ปรับดัง/ปิดเสียงแยกทุกอย่าง และอัปโหลดเสียงเอฟเฟกต์ของตัวเองได้
- โปรไฟล์การตั้งค่า: เก็บหลายชุด สลับได้ตามเกมหรือตามไลฟ์

**📊 หลังไลฟ์**
- สรุปไลฟ์: เหรียญที่ได้, คนส่งมากที่สุด, ของขวัญแต่ละชนิด บันทึกเป็นไฟล์ในโฟลเดอร์ เปิดอ่านย้อนหลังได้

**⚙️ อื่น ๆ**
- หน้าตั้งค่า 8 ภาษา: ไทย, English, 日本語, 中文, 한국어, Tiếng Việt, Indonesia, Español
- ธีมชมพู / ขาว / ดำ / น้ำเงิน
- อัปเดตอัตโนมัติ: ตรวจลายเซ็นไฟล์ ลองเปิดก่อนใช้ สำรองการตั้งค่าให้ ย้อนกลับได้

## ติดตั้ง
1. ดับเบิลคลิก `KuminBonk-v1.0.0-ติดตั้ง.exe` (ถ้า Windows เตือน กด More info → Run anyway)
2. เปิด VTube Studio → ตั้งค่า → เปิด **Start API (allow plugins)** แล้วกด Allow เมื่อมีหน้าต่างถาม
3. ในแอปพิมพ์ชื่อบัญชี TikTok ของคุณ เปิดไลฟ์ แล้วกด **เชื่อมต่อ**

ติดตั้งครั้งเดียวพอ เวอร์ชันใหม่แอปจะอัปเดตให้เอง การตั้งค่าไม่หาย

## อัปเดตอัตโนมัติทำงานยังไง
แอปเช็กโฟลเดอร์ [`updates/`](updates) ของที่เก็บนี้ตอนเปิดแอปและทุก 6 ชั่วโมง
`latest.json` บอกเวอร์ชันล่าสุดและลายเซ็น SHA-256 ส่วน `update-<เวอร์ชัน>.json.gz` คือชุดโค้ดใหม่
ก่อนออกทุกเวอร์ชัน `tools/check.mjs` ทดสอบให้อัตโนมัติ (การทำงาน, ความปลอดภัย, โหลดหนัก 300 ชิ้น, คลิกทุกหน้า) ไม่ผ่านจะไม่ยอมสร้างอัปเดต

รูปของขวัญ TikTok เป็นของ TikTok จึงไม่ได้อยู่ในที่เก็บนี้ มากับตัวติดตั้งเท่านั้น

## สำหรับนักพัฒนา
```
npm install
node src/server.js                     # เปิดที่ http://localhost:3939
node test/mock-vts.js                  # VTube Studio จำลองสำหรับทดสอบ
node tools/check.mjs                   # ตรวจทุกอย่างก่อนออกเวอร์ชัน
node tools/make-update.mjs <version>   # สร้างไฟล์อัปเดตใน updates/ (ตรวจให้ก่อนเสมอ)
python3 tools/build-setup.py <version> # ตัวติดตั้ง .exe ไฟล์เดียว (ต้องมี mono-mcs)
```
ใช้ [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector) อ่านไลฟ์ และ [VTube Studio API](https://github.com/DenchiSoft/VTubeStudio) ควบคุมโมเดล
