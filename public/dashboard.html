เช็กลิสต์ก่อนไลฟ์

  1. เปิด VTube Studio → ตั้งค่า → เปิด Start API (allow plugins) แล้วกด Allow เมื่อมีหน้าต่างถาม
  2. ตอน VTube Studio ถามว่าให้ KuminBonk โหลดรูปเป็นไอเท็ม ได้ไหม → กด Allow (ของที่ปาจะบินอยู่ในหน้าต่าง VTS เลย TikTok LIVE Studio จึงเห็นด้วย)
  3. กดปุ่ม 🔇 กดเพื่อเปิดเสียง ด้านบน แล้วเปิดหน้านี้ค้างไว้ เสียงป๊อก! จะออกลำโพงคอม (ใน TikTok LIVE Studio เปิดเสียงคอมพิวเตอร์ไว้ด้วย)
  4. ไปแท็บ 🎯 เล็งหัว ลากเป้าไปไว้ที่หัวตัวละคร (ดูเป้าสีชมพูในหน้าต่าง VTube Studio)
  5. แท็บ 🧪 ทดสอบ กดส่งกุหลาบดูว่าโดนหัวไหม

    ปรับละเอียด

    กดลูกศรทีละนิด หรือใช้ปุ่มลูกศรบนคีย์บอร์ดตอนอยู่หน้านี้

    ตั้งเป้าแยกตามหมวดของขวัญ

    ตั้งหัวให้ตรงก่อน แล้วกดหมวดด้านล่าง (เช่น ขนมเข้าปาก → ปาก, คล้องคอ → คอ, รถชน → ตัว) หรือของขวัญชิ้นเดียว แล้วลากจุดไปตรงที่อยากให้โดน จุดจาง ๆ คือหัว · ถ้าขยับหัว/โมเดล เป้าของหมวดจะเลื่อนตามไปด้วย · ของขวัญที่ตั้งเฉพาะชิ้นจะใช้ค่าของชิ้นนั้นก่อนหมวด

    การปาของ

    ข้อความขอบคุณบนจอ (ไม่บังคับ)

    การกระทำ "💬 ข้อความบนจอ" ต้องใช้ overlay: ใน TikTok LIVE Studio กด เพิ่มแหล่งที่มา → ลิงก์ (Link) แล้ววางลิงก์นี้ ขนาด 1920×1080 ถ้าลิงก์ขึ้นเป็นจุดเล็ก ๆ แปลว่า LIVE Studio มีบั๊ก ข้ามส่วนนี้ไปได้ ของที่ปายังบินใน VTS ตามปกติ
