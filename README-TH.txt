ติดตั้ง (ครั้งแรก)
-----------------
1) ดับเบิลคลิกไฟล์ "KuminBonk-v<เวอร์ชัน>-ติดตั้ง.exe"
   - จะขึ้นหน้าต่างติดตั้งสีชมพู มีแถบความคืบหน้า ดาวน์โหลดตัวรันโปรแกรม (Node.js) จาก nodejs.org
     และตรวจลายเซ็นไฟล์ให้อัตโนมัติ
   - ถ้า Windows ขึ้น "Windows protected your PC" ให้กด More info → Run anyway
   - เสร็จแล้วจะมีไอคอน KuminBonk บนเดสก์ท็อป + เมนู Start และโปรแกรมจะเปิดขึ้นมาเอง
   - ถอนการติดตั้ง: Settings → Apps → KuminBonk → Uninstall
   (หรือใช้แบบ zip: แตก zip แล้วดับเบิลคลิก "ติดตั้ง KuminBonk.cmd" ก็ได้เหมือนกัน)
2) ติดตั้งครั้งเดียวพอ เวอร์ชันใหม่ ๆ แอปอัปเดตให้เอง
3) ก่อนใช้: เปิด VTube Studio → ตั้งค่า (รูปฟันเฟือง) → เปิด "Start API (allow plugins)"
   ครั้งต่อไปเปิด KuminBonk จากไอคอนได้เลย  ปิดหน้าต่าง = ปิดโปรแกรม
4) VTube Studio จะถาม 2 ครั้ง กด Allow ทั้งสองครั้ง
   (ก) ให้ปลั๊กอิน KuminBonk เชื่อมต่อ   (ข) ให้ KuminBonk โหลดรูปเป็นไอเท็ม (ใช้แสดงของขวัญ)
5) แท็บ "🎯 เล็งหัว" → ลากเป้า ดูเป้าสีชมพูในหน้าต่าง VTube Studio ให้ตรงหัว → บันทึก
6) แท็บ "🧪 ทดสอบ" → กดรูปของขวัญในหัวข้อ "ลองดูท่าของขวัญแต่ละชิ้น" เพื่อดูท่า
7) เปิดไลฟ์ใน TikTok LIVE Studio แล้วกด "เชื่อมต่อ" ในหน้าหลัก
   (ติ๊ก "เชื่อมต่ออัตโนมัติ" ไว้ ครั้งหน้าแค่เปิดโปรแกรมก็พอ)
   เสียงเอฟเฟกต์ออกลำโพงคอม → ใน TikTok LIVE Studio เปิดการจับเสียงคอมพิวเตอร์ไว้

ท่าตามของขวัญ (ใส่รูปของขวัญจริงครบ 258 ชิ้น)
---------------------------------------------
แต่ละชิ้นมีท่าของตัวเองตามรูป เช่น
  🚗 รถ/รถไฟ/มอเตอร์ไซค์ → พุ่งมาชน ตัวละครกระเด็น
  🎩 หมวก/หูฟัง/แว่น/มงกุฎ → หล่นลงมาใส่หัว
  🍩 โดนัท/ไอศกรีม/เค้ก/น้ำ → บินเข้าปาก ง่ำ ๆ
  🎸 เครื่องดนตรีทุกชนิด → มาเล่นข้าง ๆ ตัวละครโยกตามจังหวะ โน้ตลอย
  🐶 แมว/หมา/สัตว์น่ารัก → วิ่งมานั่งบนหัว   🦁 สิงโต/มังกร → คำราม ตัวละครตกใจ
  ✈️ เครื่องบิน/นก/วาฬ → บินผ่าน ตัวละครหันมองตาม   🚀 จรวด → พุ่งขึ้นฟ้า สั่นสะเทือน
  ☄️ ดาวตก/ดาว PK → อุกกาบาตตกใส่หัว ตัวดำ   ⚡ สายฟ้า → ไฟช็อต
  💸 ปืนพ่นเงิน/ปืนยิงเพชร → ยิงเงินใส่รัว ๆ   🎆 พลุ/ปาร์ตี้ → คอนเฟตติระเบิด
  💖 หัวใจ/รัก → หัวใจลอย ตัวละครเขิน   🌸 ดอกไม้ → กลีบดอกไม้โปรย
  👍 นิ้ว/ปรบมือ → ลูบหัว   ⚽ ฟุตบอล → บอลเด้งหัว   GG/สติกเกอร์ → แปะหน้า
  🧊 น้ำแข็ง → แช่แข็ง หนาวสั่น   🔥 ฟีนิกซ์ → ไฟลุก   🕷️ แมงมุม → ห้อยลงมา ตกใจ
  🌹 กุหลาบ → ปาใส่หัว โดนตี (แบบเดิม)
ยิ่งของขวัญแพง ท่ายิ่งแรง  ของขวัญ 1,000+ หมุนตัว  10,000+ จัดเต็มปาร์ตี้

ปรับได้เองในแท็บ "🎁 ของขวัญ & เอฟเฟกต์": ทุกกฎมีการกระทำ "🎭 ท่าตามของขวัญ"
เลือก "อัตโนมัติ" หรือบังคับท่าที่ชอบได้ และเพิ่มกฎเฉพาะของขวัญชิ้นไหนก็ได้ (กด 🎁 เลือกของขวัญ)

เป้าแยกตามหมวด (ใหม่ v1.4.2)
-----------------------------
แท็บ "🎯 เล็งหัว": ตั้งหัวให้ตรงก่อน แล้วกดหมวดทางขวา (เช่น บินเข้าปาก) ลากเป้าไปตรงปาก → บันทึก
ทำแบบเดียวกันกับคล้องคอ (คอ), รถชน (ตัว) ฯลฯ หรือพิมพ์ชื่อของขวัญเพื่อตั้งเฉพาะชิ้น · ↺ กลับค่าเริ่มต้นได้

ตั้งค่าแยกตามหมวด (ใหม่ v1.4)
-----------------------------
แท็บ "🎭 หมวดของขวัญ": ทุกหมวด (ปาใส่หัว, รถชน, หมวก, ดนตรี ฯลฯ) ปรับแยกกันได้
  เปิด/ปิด · ขนาดรูป · ความแรง · ความเร็ว · สูงสุดต่อครั้ง · เสียง · เปลี่ยนไปใช้ท่าอื่น
กดรูปของขวัญในหมวด → ย้ายชิ้นนั้นไปท่าอื่น หรือตั้งขนาดเฉพาะชิ้นนั้น
รูปของขวัญใหญ่ตามราคา และของขวัญตั้งแต่ 1,000 เหรียญจะ "อวด" ตัวใหญ่กลางจอก่อน (ปรับได้)

อัปเดตอัตโนมัติ (ใหม่ v1.4)
--------------------------
ติดตั้ง v1.4 ครั้งเดียว จากนั้นแอปจะเช็กเวอร์ชันใหม่เองทุกครั้งที่เปิด ดาวน์โหลดเบื้องหลัง
แอปจะ "ลองเปิด" เวอร์ชันใหม่เพื่อตรวจก่อน ผ่านแล้วถึงจะใช้ + สำรองการตั้งค่าให้อัตโนมัติ
แล้วขึ้นแถบเหลือง "✅ ตรวจผ่านแล้ว" → กดรีสตาร์ท หรือรอเปิดครั้งหน้าก็ได้ (การตั้งค่าไม่หาย)
ถ้าเวอร์ชันใหม่เปิดไม่ขึ้น ครั้งถัดไปจะกลับไปใช้เวอร์ชันเดิมเอง
แท็บตั้งค่า: ปุ่มย้อนกลับเวอร์ชันก่อนหน้า, สำรองการตั้งค่าตอนนี้, กู้คืนชุดที่สำรองไว้

ข้อควรรู้เรื่องชื่อของขวัญ
--------------------------
ตอนไลฟ์ TikTok ส่งชื่อของขวัญมาเป็นภาษาอังกฤษ ของขวัญยอดนิยมแอปรู้ชื่ออยู่แล้ว ของขวัญที่ราคาไม่ซ้ำ
แอปจับคู่จากราคาให้เอง ส่วนชิ้นที่ราคาซ้ำกันหลายชิ้น ถ้ายังจับคู่ไม่ได้จะใช้ "ปาใส่หัว" แทน
(กฎช่วงราคายังทำงานเสมอ) ถ้าอยากให้ชิ้นนั้นมีท่าเฉพาะ: ส่งชิ้นนั้นมาสักครั้ง แล้วใน "เลือกของขวัญ"
→ ส่วน "ของขวัญที่เคยได้รับจริง" → เลือกชิ้นนั้นในกฎใหม่ แล้วตั้ง "🎭 ท่าตามของขวัญ" เป็นท่าที่ต้องการ

ปัญหาที่เจอบ่อย
---------------
- เปิดแล้วไม่มีหน้าต่างขึ้น: ดูไฟล์บันทึกที่ %APPDATA%\KuminBonk\log.txt
  (พิมพ์ %APPDATA%\KuminBonk ในช่องที่อยู่ของ File Explorer)
- VTS ไม่เขียว: ยังไม่ได้เปิด Start API หรือยังไม่ได้กด Allow
  (ถ้ากด Deny ไปแล้ว ลบไฟล์ %APPDATA%\KuminBonk\vts-token.txt แล้วเปิดโปรแกรมใหม่)
- ตัวละครสะดุ้งแต่ไม่เห็นของ: ยังไม่ได้อนุญาต "โหลดรูปเป็นไอเท็ม"
  → VTube Studio ตั้งค่า → API → KuminBonk → เปิด Load custom images as items
- ของไม่ตรงหัว: ไปแท็บเล็งหัวใหม่
- TikTok "หาไลฟ์ไม่เจอ": ต้องเปิดไลฟ์ก่อน และชื่อต้องตรงกับใน URL tiktok.com/@ชื่อ
- เชื่อมต่อบ่อยแล้วโดนจำกัด: สมัคร API key ฟรีที่ eulerstream.com ใส่ในแท็บตั้งค่า
- การตั้งค่าทั้งหมดเก็บที่ %APPDATA%\KuminBonk (อัปเดตเวอร์ชันใหม่ การตั้งค่าไม่หาย)

ข้อจำกัด: TikTok ไม่มี API ทางการ โปรแกรมนี้อ่านไลฟ์ผ่านไลบรารี tiktok-live-connector + Euler Stream
ถ้า TikTok เปลี่ยนระบบ อาจต้องอัปเดตไลบรารี โปรแกรมไม่ขอรหัสผ่าน TikTok ใด ๆ ทั้งสิ้น
